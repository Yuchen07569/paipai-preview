# 排排天津排球公开测试版

这是一个手机优先的可安装 PWA，供天津排球用户试用并反馈产品建议，包含：

- 新用户注册与排球经验设置。
- 首页推荐、附近场地和公开资料地图。
- 场地详情可选择腾讯地图、百度地图或高德地图打开位置。
- 活动日期横向筛选、场地地图/列表切换、五图画廊和详情页固定操作区。
- 明亮的排球主题视觉、场地地图、个人能力卡与运动日历。
- 场地地图使用真实 OpenStreetMap 瓦片，支持拖动、滚轮/按钮/双指缩放，并通过“编号＋场地名”标记和底部预览卡识别地点。
- 活动列表、详情、单人报名与状态流转。
- 活动参与意向、取消和站内通知。
- 场地资料助手、球友消息、好友、收藏与“我的”。

场地资料来自公开来源，开放与预约状态需向场馆复核。活动页用于收集参与意向，活动成行前不产生扣款或场地订单。

## 打开

在本目录运行：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

随后打开：

```text
http://127.0.0.1:4173
```

同一 Wi-Fi 下，可用电脑的局域网 IP 在手机打开：

```text
http://电脑局域网IP:4173
```

稳定公网地址和 PWA 安装需要 HTTPS 部署；部署前单独确认平台、账号与费用。

## 验证

```bash
node --test app.test.mjs product.test.mjs
```

测试覆盖场地排序、公开资料问答边界、三地图链接、剩余名额、注册资料校验和报名状态机。

## 数据边界

- 场地名称、地址和设施来自公开地图、场馆官网、政府或公共信息页面。
- 数据整理日期为 2026-08-25。
- 商家与用户图片尚未接入，合作后上传获得授权的真实场地图。
- 地图上存在不等于当前可订；每个场地都单独显示开放信息是否需要复核。
- 内置地图使用 OpenStreetMap/CARTO 底图；外部导航同时支持腾讯、百度和高德，产品只维护一套坐标与场地事实源。
- 当前账号、报名、收藏和消息保存在浏览器 `localStorage`；清理浏览器数据会重置体验。
- 多用户、真实短信、组织者后台、图片上传、审核和支付需要 CloudBase 等生产服务。
